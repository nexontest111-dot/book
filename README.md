# 플레이약속

골프·사회인야구 시설의 공개 슬롯을 기준으로 참가자 약속과 예약을 함께 처리하는 서비스입니다. PC·모바일 브라우저용 반응형 웹을 계획하고 있습니다.

개발 브랜치에서는 Supabase 이메일 가입·인증·로그인과 PostgreSQL 공개 시설 조회가 개발 사이트에 배포돼 확인됐습니다. 기존 예약·시설 관리 화면은 시안이며 실제 예약·결제와 연결되지 않았습니다. 상세한 완료 범위와 다음 작업은 인수인계 문서를 확인하세요.
