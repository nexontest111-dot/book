# 플레이약속 화면 시안

`index.html`을 PC 또는 모바일 브라우저에서 열면 사용할 수 있습니다. 패키지 설치나 빌드가 필요 없습니다. 외부 글꼴이 연결되지 않으면 시스템 글꼴을 사용합니다.

## 확인 가능한 흐름

1. 골프 개인 조인 또는 야구 경기 매칭 슬롯을 선택합니다.
2. 상대 참가자·팀 이름과 희망 조건을 작성합니다.
3. 내 동의와 상대방 동의 시뮬레이션 버튼으로 결제 대기에 진입합니다.
4. 내 모의 결제와 상대방 모의 결제를 각각 실행하면 예약이 모의 확정됩니다.
5. 한쪽만 결제하고 '기한 만료시키기'를 실행하면 슬롯 해제와 모의 전액 환불 상태를 확인할 수 있습니다.
6. 시설 관리에서 슬롯을 추가하거나 공개를 중지할 수 있습니다.

## 범위와 제한

- 실제 시설 정보·로그인·채팅 전달·서버 권한·결제·환불은 연결하지 않았습니다.
- 수수료 각 3,000원은 데모 금액이며 확정된 사업 정책이 아닙니다.
- 양측은 데모 화면에서 직접 조작합니다. 실제 계정 간 동기화가 아닙니다.
- 데이터는 현재 브라우저의 localStorage에 저장됩니다. 저장 차단 시 해당 페이지 세션에서만 유지됩니다. 파일 직접 실행 시 브라우저에 따라 저장 동작이 다를 수 있습니다.
- 슬롯 충돌 검사는 같은 시설 이름의 시간 겹침에 대한 단순 시뮬레이션입니다. 실제 구현은 구장·코스·티타임·좌석 수량을 구분해야 합니다.
- 골프 개인 조인은 두 당사자 협의 예시이며 다수 참가자와 청구 단위는 추가 설계가 필요합니다.
- 단독 골프 팀 예약과 야구장 대관은 과금 정책이 미정이라 문의까지만 제공합니다.
- 최종 확정 이후 취소·변경 정책은 미정이므로 해당 처리를 제공하지 않습니다.
- 새 슬롯은 종료시간이 시작시간보다 늦은 당일 이용만 지원합니다.
- 테스트·빌드·배포는 실행하지 않았습니다.

프로덕션 프레임워크와 PG는 선택하지 않았습니다. 정적 시안의 구조는 실제 서버 설계와 분리됩니다.
